# Configurador OEE

Artefacto de la tesis "Integración de Lean Manufacturing e Industria 4.0 para la mejora de la eficiencia operativa en MYPE de confección de jeans" (UPC).

Aplicación en Streamlit con cinco pasos: datos de planta, línea base, configuración de cámaras y sensores, acciones, y carga diaria del prototipo (sensores IoT y cámara).

Archivo principal: `app.py`.
